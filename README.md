# Kaizen Finance CLI

A Python-based personal finance management application designed to help users record, organise and analyse their personal finances through a command-line interface.

## Project Overview

Kaizen Finance CLI is the first software development project in Project Kaizen, a continuous learning and engineering development initiative.

The application aims to provide a simple way to manage personal income and expenses, monitor spending habits, and understand financial activity.

## Objectives

- Practise Python programming fundamentals.
- Apply object-oriented programming principles.
- Learn data storage and file handling.
- Develop problem-solving and software design skills.
- Practise Git and GitHub version control.

## Planned Features

- Record income.
- Record expenses.
- Categorise transactions.
- View transaction history.
- Calculate total income and expenses.
- Display current balance.
- Generate financial summaries.
- Save financial records for future sessions.

## Technologies

- **Language:** Python
- **Interface:** Command-Line Interface (CLI)
- **Version Control:** Git
- **Repository Hosting:** GitHub

## Project Structure

The application will be developed incrementally as new functionality is introduced.
